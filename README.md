This project is a comprehensive e-commerce platform designed to showcase a wide range of electronic gadgets, including phones, tablets, and accessories. It emphasizes a user-friendly experience with intuitive navigation, detailed product views, and essential e-commerce functionalities like shopping cart management and a favorites list. The application is built with a strong focus on modern web development practices, ensuring responsiveness across devices and offering a dark mode for enhanced user comfort.

## ✨ Features

- **Product Catalog:** Browse products by category (Phones, Tablets, Accessories).
- **Product Details Page:** View detailed information for each product, including a photo gallery with a swiper.
- **Product Cards:** Each product is displayed on a card with essential information and quick actions.
- **Add to Cart & Favorites:** Users can add products to the shopping cart and save them to a favorites list directly from the product card or the details page.
- **Filtering and Sorting:** Filter products by query and sort them by price or name.
- **Shopping Cart:** A dedicated page to view and manage items in the cart.
- **Favorites:** A dedicated page to view and manage favorite items.
- **Responsive Design:** The application is optimized for various screen sizes.
- **Dark Mode:** Switch between light and dark themes.

## 🏁 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

- Node.js (v20 or higher)
- npm

### Environment Variables

To run the application with a different backend host, you need to create a `.env` file in the root of the project and add the following variable:

```sh
VITE_API_HOST=your_api_host_url
```

### Installation

1. **Clone the repo**

   ```sh
   git clone https://github.com/your_username/nice-gadget-store-demo.git
   ```

2. **Navigate to the project directory**

   ```sh
   cd nice-gadget-store-demo
   ```

3. **Install NPM packages**

   ```sh
   npm install
   ```

### Running the Application

To start the development server, run:

```sh
npm start
```

This will open the app in your default browser at `http://localhost:5173`.

## 📜 Available Scripts

In the project directory, you can run:

- `npm start`: Runs the app in the development mode.
- `npm run build`: Builds the app for production to the `build` folder.
- `npm run lint`: Lints the code using ESLint, Prettier, and Stylelint.
- `npm run format`: Formats the code with Prettier.
- `npm run deploy`: Deploys the application to GitHub Pages.
